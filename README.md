# hsbo-brand

Quarto-Brand der Hochschule Bochum: Name, Link, Logo und (geplant) Farben und Schrift. Passt zu den
Extensions aus [quarto-tinh](https://github.com/matthiasbaitsch/quarto-tinh), die nur Layout und Stil enthalten.

## Einbinden

Im Projektverzeichnis:

```bash
quarto use brand matthiasbaitsch/hsbo-brand
```

Quarto kopiert `_brand.yml` und die Dateien, auf die sie verweist, nach `_brand/` im Projekt. Aktualisieren mit
demselben Befehl.

## Offen

- Logo als Datei statt URL, sobald geklärt ist, ob es weitergegeben werden darf
- Farben und ggf. Schrift nach den Gestaltungsrichtlinien der HS
